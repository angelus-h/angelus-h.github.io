# Operational Lessons from Professional Experience

**Purpose:** Extract practical, operational lessons from real professional experiences using structured analysis.

**Approach:** Fact-driven, non-diagnostic, focused on observable patterns and concrete actions.

---

## How to Use This Framework

### Core Principles

1. **Observable facts only** - No speculation without explicit labeling
2. **Separate fact from interpretation** - Clear distinction between what happened and what it meant
3. **No psychological diagnoses** - Focus on behavior patterns, not labels
4. **Explicit uncertainty** - Mark what is known vs. unknown
4. **Internet validation** - Cross-check claims where possible
5. **Operational focus** - Extract actionable lessons, not drama

### When to Document an Experience

Document when:
- Pattern repeats across situations
- Lesson has broad applicability
- Mistake was costly (time, energy, career)
- Success was non-obvious
- Future prevention is possible

Don't document:
- One-off events with no pattern
- Experiences still too fresh (wait 3-6 months for perspective)
- Situations where facts cannot be separated from emotion yet
